La parte de Grafana la resolvimos generando archivos JSON a partir de los logs del daemon, para luego exponerlos mediante un pequeño servidor HTTP y consumirlos desde Grafana usando el datasource Infinity. Primero, el daemon fue guardando métricas y eventos en monitor_logs.jsonl; después se creó un script que transforma esos registros en archivos más fáciles de graficar, como summary_latest.json, ram_timeseries.json, deleted_containers.json, top_rss_latest.json y top_cpu_latest.json. Luego levantamos un servicio json_api en Docker para servir esos archivos por HTTP y configuramos Grafana con el plugin Infinity para leerlos desde URLs internas del stack, por ejemplo http://json_api:8080/summary_latest.json. Con eso construimos un dashboard con tarjetas para RAM total, usada y libre, una gráfica temporal del uso de RAM, un panel de contenedores eliminados en el tiempo y paneles para el top 5 por memoria y por CPU.
